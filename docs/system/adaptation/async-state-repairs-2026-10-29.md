## 可选 Java 验证问题的处理

原夹具用普通 Thymeleaf `3.1.5` 时会出现 Links/Jackson 属性解析失败；不是凭此就修改线上模板。核对 [Halo 2.27.1 官方随包依赖](https://github.com/halo-dev/halo/tree/v2.27.1/application/libs)后，使用仓库内 `thymeleaf-3.1.3.RELEASE.jar` 和 `thymeleaf-spring6-3.1.3.RELEASE.jar`，保留原模板和断言，**228 个评论模板场景、652 条断言全部通过**。

导航夹具改用 `javac`/`java` 编译执行，替代需要独立执行引擎的 JShell；运行失败仍报错，不跳过断言。配套官方 Thymeleaf 包下导航 75/75 通过。认证三项可选用例使用现场 `/js/main.js?v=2.27.1`，也纳入本批 362 项总数。

这些是离线夹具：其他 Spring/Jackson 依赖来自本机缓存，清单与哈希已记录，不等同于完整 Halo 进程的依赖组合。复跑时设置 `SKY_UI_JAVA_FIXTURE_CLASSPATH`（含上述官方包及运行依赖）、`JAVA_HOME`、`HALO_AUTH_CORE_SCRIPT`，然后运行现有验证命令；不自动下载依赖或启动 Halo。

## 人工复验

所有地址均需附加 `preview-theme=theme-sky-blog-1`，否则看到的是活动主题 3。

- 图库：打开 `/photos?size=1&preview-theme=theme-sky-blog-1`，持续向下滚动，当前数据应能到 46 张。默认 `/photos` 也应继续翻页；开发者工具临时断网后出现重试，恢复网络再点重试。
- 友链：打开 `/links?view=apply&preview-theme=theme-sky-blog-1`，使用网络限速让识别延迟，识别过程中改网址；旧结果不得填入新网址。公开站点若受 CORS 限制，手填降级是预期行为；确定性竞态需使用本批响应替身。
- 追番：打开 `/bangumis?preview-theme=theme-sky-blog-1`，鼠标在两张封面间快速 A→B→A，停留后背景应对应 A。
- 天气：本站当前背景模式不触发此分支；本批故障注入方法见浏览器脚本，不需要为了验收修改站点配置。
