## 修复了什么

`scripts/verify-plugin-pages.mjs` 原先把 `comment-content-` 当作所有评论的必要标记。实际 DocTree 使用 `comment-doc-halo-run-…`，导致页面 200、官方组件正常时仍报失败。

现按实际输出校验：页面中存在评论容器，并且同一个模块从官方版本化资源导入 `init`、初始化到该容器。保留主题身份、资源版本和评论区检查，不把“只加载了脚本”当作挂载成功。`scripts/verify-plugin-pages-scope.mjs` 新增 10 个 HTTP 用例，覆盖 Post、DocTree、Moment 和缺容器、错 ID、假宿主、非官方初始化等反例；该组 **24/24** 通过。

方法依据为 [Halo 官方主题插件集成](https://docs.halo.run/developer-guide/theme/plugin-integration)、[Comment Widget 官方主题契约](https://github.com/halo-dev/plugin-comment-widget/blob/82cf890f94821589e4231fb7fa874aee3ec48c76/dev/theme-integration.md)，并核对本地 3.5.0 的实际模块、挂载 HTML 和组件。技能说明用于定位契约，实际页面与测试记录才是本次证据。

首次补 URL 检查保留 **43 通过、2 失败、3 未覆盖**：评论是上述探针错误；Feed XML 为一次 10 秒超时。Feed 随后三次独立 GET 均为 200、RSS/channel 完整，最终探针也通过；原超时原因未定位，不宣称修复了 Feed 插件。
