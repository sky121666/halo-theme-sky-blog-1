## 修复与验收

| 审计项 | 原因与实际修改 | 验证 |
| --- | --- | --- |
| R4 Steam 分页乱序 | `src/pages/steam/steam.js` 为 games 单独创建取消控制器，只允许当前请求更新列表、错误和 loading；离页取消；取消后不再尝试备用 API，普通错误仍保留原回退 | 5 项回归，修复前 4 失败；修复后全通过。实际插件在 390/1440 宽度正常翻页。真实 Alpine + 键盘 + 受控响应按 3、1 请求，按 1、3 返回，最终保留第 1 页 |
| R1 文档/文章抽屉 | 模板默认 inert/aria-hidden，关闭态 CSS 隐藏；`modal-focus.js` 统一首焦点、正反 Tab、Escape、背景 inert、滚动恢复和离页清理。移除页面清理时无条件清空 body overflow。FAB 项关闭后不可见时回到可见展开入口 | 文档菜单、文档目录、文章目录在实际手机宽度页面通过打开、正反 Tab、关闭和恢复。生产片段的 390/1440 检查通过。实际文档抽屉内导航及历史返回等待 sky:page-load 和目标正文，两次均为同 document，滚动恢复、抽屉关闭 |
| R2 瞬间发布弹窗 | 复用相同焦点管理；保留原发布权限、提交锁和草稿判断。表情选择器移动到所属模态范围，避免被背景 inert 或焦点约束阻挡 | 生产模板/脚本 + 隔离权限响应，在 390/1440 通过 Escape、焦点约束、恢复、真实表情选择和离页清理。未登录发布、上传或提交瞬间 |
| R3 悬停控件键盘不可见 | 照片翻页补 focus-visible；文章标题锚点从内联透明度/鼠标监听改为 CSS hover/focus-within | 实际照片详情与文章页在 390/1440 下键盘聚焦可见；生产片段交叉验证通过 |

焦点处理依据 [W3C APG 模态对话框规范](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)。共同辅助模块只处理这些原生抽屉/发布弹窗的界面状态，没有扩展插件能力或改造其他弹窗。

## 人工复验入口

统一追加 `?preview-theme=theme-sky-blog-1`；开发环境浏览器先禁缓存重载。

1. `/steam`：正常翻页；慢网快速反向切换后应保持最后选择，旧请求不得清除新请求的加载/错误状态。三页乱序使用隔离响应复现，本地真实库目前两页。
2. `/docs/halo-theme-sky-blog-1/theme-settings/global`：手机宽度下展开文档工具，打开菜单/目录；Tab、Shift+Tab 不离开面板，Escape 关闭并回到可见入口；从菜单进入文档后返回，滚动和交互仍正常。
3. `/archives/editor-feature-demo`：手机打开目录，按上述检查；桌面/手机用 Tab 进入标题的复制链接，应显示图标。
4. `/photos/photo-14xk1htg`：鼠标移出图片后用 Tab 聚焦上一张/下一张，图标不能透明。
5. `/moments`：有官方发布权限时检查编辑弹窗；本批只使用隔离权限样本测试弹窗和表情，实际站点匿名访问不显示发布入口。无需为验收发送真实内容。
