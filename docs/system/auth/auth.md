# 认证页面

认证页面用于控制登录、注册等 Halo 认证入口的展示样式。它只改前台样式，不改变 Halo 的账号、权限和认证逻辑。

| 项目     | 说明                                       |
| -------- | ------------------------------------------ |
| 页面     | 登录页、注册页等认证页面                   |
| 设置位置 | `外观 -> 主题 -> Sky Blog -> 设置 -> 认证` |
| 相关插件 | Passkey 等认证插件可按 Halo 原有机制接入   |

## 布局选择

| 布局     | 说明                       | 适合场景                 |
| -------- | -------------------------- | ------------------------ |
| 系统默认 | 使用 Halo 默认认证页面     | 想保持最稳、最少样式干预 |
| 分屏布局 | 左侧品牌展示，右侧登录表单 | 想突出站点品牌           |
| 居中卡片 | 表单位于页面中心           | 想保持简洁登录体验       |

## 全量配置项

### 认证样式 `auth_settings`

| 设置项       | 字段                     | 说明                         |
| ------------ | ------------------------ | ---------------------------- |
| 认证页布局   | `auth_layout`            | 系统默认、分屏布局或居中卡片 |
| 品牌区样式   | `brand_style`            | 分屏布局下的左侧品牌展示样式 |
| 卡片效果     | `card_effect`            | 居中卡片下的视觉效果         |
| 简约站点标题 | `auth_site_title_simple` | 简约品牌样式使用的站点标题   |
| 品牌标语     | `brand_slogan`           | 分屏品牌展示区的标语         |
| Logo         | `auth_logo`              | 功能特性样式使用的 Logo      |
| 站点标题     | `auth_site_title`        | 功能特性样式使用的标题       |
| 侧边背景图   | `auth_side_image`        | 分屏布局左侧背景图           |
| 功能欢迎语   | `features_welcome`       | 功能特性区域的欢迎文案       |
| 特性 1 图标  | `feature_1_icon`         | 第一条功能说明图标           |
| 特性 1 标题  | `feature_1_title`        | 第一条功能说明标题           |
| 特性 1 描述  | `feature_1_desc`         | 第一条功能说明描述           |
| 特性 2 图标  | `feature_2_icon`         | 第二条功能说明图标           |
| 特性 2 标题  | `feature_2_title`        | 第二条功能说明标题           |
| 特性 2 描述  | `feature_2_desc`         | 第二条功能说明描述           |
| 特性 3 图标  | `feature_3_icon`         | 第三条功能说明图标           |
| 特性 3 标题  | `feature_3_title`        | 第三条功能说明标题           |
| 特性 3 描述  | `feature_3_desc`         | 第三条功能说明描述           |

## 分屏布局

分屏布局需要继续选择品牌区样式：

| 样式     | 说明                                  |
| -------- | ------------------------------------- |
| 简约品牌 | 展示站点标题和品牌标语                |
| 功能特性 | 展示 Logo、标题、背景图和三条功能说明 |
| 动态插画 | 展示更强的登录页视觉互动              |

可配置内容：

| 设置项   | 说明                               |
| -------- | ---------------------------------- |
| 站点标题 | 留空时使用站点默认标题             |
| 品牌标语 | 显示在品牌展示区                   |
| Logo     | 功能特性样式下可单独上传           |
| 背景图   | 功能特性样式下可替换左侧背景       |
| 特性文案 | 配置三条功能说明的图标、标题和描述 |

## 居中卡片

| 设置项   | 说明                     |
| -------- | ------------------------ |
| 卡片效果 | 支持 3D 倾斜或聚光灯效果 |

如果认证页要尽量轻量，建议使用“系统默认”或“居中卡片”。

## 兼容注意事项

| 场景         | 建议                                                   |
| ------------ | ------------------------------------------------------ |
| 使用 Passkey | 保留 Halo 登录表单结构，避免破坏插件注入的认证入口     |
| 登录按钮异常 | 检查认证插件是否启用，再切回“系统默认”确认是否主题相关 |
| 注册页异常   | 确认 Halo 是否允许注册，以及当前站点认证设置是否开放   |
| 样式错位     | 先切换到系统默认复测，再检查浏览器控制台错误           |
