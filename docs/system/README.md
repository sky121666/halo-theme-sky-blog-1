# 系统与维护

系统文档按“认证、开发、适配”拆分，不属于普通页面内容，但会影响主题稳定性。

| 二级目录      | 内容                               | 入口                                |
| ------------- | ---------------------------------- | ----------------------------------- |
| `auth`        | 登录页布局、认证主题、Passkey 兼容 | [认证](./auth/README.md)            |
| `development` | 构建、PJAX、页面脚本、资源缓存     | [开发维护](./development/README.md) |
| `adaptation`  | 插件版本基线、适配边界、验收清单   | [插件适配](./adaptation/README.md)  |

## 使用场景

| 场景                   | 先看                                |
| ---------------------- | ----------------------------------- |
| 登录页异常             | [认证](./auth/README.md)            |
| 修改前端资源或页面脚本 | [开发维护](./development/README.md) |
| 升级插件或排查插件页面 | [插件适配](./adaptation/README.md)  |
