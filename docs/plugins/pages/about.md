# 关于页面

关于页面用于展示个人介绍、社交链接、技术栈、站点统计、GitHub 数据、自定义内容和位置地图。

| 项目     | 说明                                       |
| -------- | ------------------------------------------ |
| 设置位置 | `外观 -> 主题 -> Sky Blog -> 设置 -> 关于` |
| 页面来源 | Halo 自定义页面或主题关于页模板            |
| 适合用途 | 个人简介、作品入口、联系方式、站点信息     |

## 页面内容

| 区域       | 做什么                                     |
| ---------- | ------------------------------------------ |
| 个人信息   | 展示头像、昵称、角色和简介                 |
| GitHub     | 展示统计卡片、常用语言和贡献热力图         |
| 社交链接   | 展示 GitHub、邮箱、Bilibili 等外部链接     |
| 技术栈     | 展示技术名称、图标和熟练度                 |
| 站点统计   | 展示文章数、分类数、评论数、访问量等统计   |
| 发布热力图 | 展示最近一年文章发布情况                   |
| 自定义内容 | 渲染页面编辑器里的正文内容                 |
| 位置地图   | 使用经纬度展示位置卡片                     |
| 评论区     | 页面底部显示评论组件，需要站点评论功能可用 |

## 全量配置项

### 个人信息 `profile`

| 设置项   | 字段       | 说明                        |
| -------- | ---------- | --------------------------- |
| 头像     | `avatar`   | 留空时使用站点 Logo         |
| 昵称     | `nickname` | 留空时使用站点名称          |
| 角色     | `role`     | 用一句话说明身份或定位      |
| 个人简介 | `bio`      | 支持简单 HTML，建议保持简短 |

### GitHub `github`

| 设置项         | 字段            | 说明                          |
| -------------- | --------------- | ----------------------------- |
| GitHub 用户名  | `username`      | 用于统计卡片和贡献热力图      |
| 显示统计卡片   | `show_stats`    | 是否显示仓库统计和常用语言    |
| 显示贡献热力图 | `show_calendar` | 是否显示 GitHub Contributions |
| 统计服务地址   | `stats_host`    | 默认服务或自部署统计服务地址  |
| 语言           | `locale`        | 控制统计卡片语言              |
| 主题           | `stats_theme`   | 控制统计卡片视觉主题          |

### 社交链接 `social_links`

| 设置项 | 字段   | 说明                     |
| ------ | ------ | ------------------------ |
| 名称   | `name` | 社交平台或链接名称       |
| 链接   | `url`  | 外部链接、邮箱或站内路径 |
| 图标   | `icon` | Iconify 图标名           |

### 技术栈 `tech_stack`

| 设置项 | 字段          | 说明                 |
| ------ | ------------- | -------------------- |
| 名称   | `name`        | 技术、工具或领域名称 |
| 图标   | `icon`        | Iconify 图标名       |
| 熟练度 | `proficiency` | 用于展示掌握程度     |

### 按钮 `hero_actions`

| 设置项     | 字段                             | 说明               |
| ---------- | -------------------------------- | ------------------ |
| 显示主按钮 | `primary_group.show_primary`     | 是否显示首屏主按钮 |
| 主按钮文字 | `primary_group.primary_text`     | 主按钮文案         |
| 主按钮链接 | `primary_group.primary_link`     | 主按钮跳转地址     |
| 显示次按钮 | `secondary_group.show_secondary` | 是否显示首屏次按钮 |
| 次按钮文字 | `secondary_group.secondary_text` | 次按钮文案         |
| 次按钮链接 | `secondary_group.secondary_link` | 次按钮跳转地址     |

### CTA `cta`

| 设置项   | 字段          | 说明                   |
| -------- | ------------- | ---------------------- |
| 显示 CTA | `show_cta`    | 是否显示页面底部行动区 |
| CTA 标题 | `title`       | 行动区标题             |
| 按钮文字 | `button_text` | CTA 按钮文案           |
| 按钮链接 | `button_link` | CTA 按钮跳转地址       |

### 展示开关 `display`

| 设置项         | 字段                   | 说明                         |
| -------------- | ---------------------- | ---------------------------- |
| 显示站点统计   | `show_site_stats`      | 是否显示文章数、分类数等统计 |
| 显示文章热力图 | `show_article_heatmap` | 是否显示最近一年发布热力图   |
| 显示页面正文   | `show_page_content`    | 是否渲染 Halo 页面编辑器正文 |
| 启用评论       | `enable_comment`       | 是否在关于页底部显示评论区   |

### 位置 `location`

| 设置项   | 字段                   | 说明                   |
| -------- | ---------------------- | ---------------------- |
| 显示位置 | `show_location`        | 是否显示位置地图卡片   |
| 纬度     | `latitude`             | 十进制纬度             |
| 经度     | `longitude`            | 十进制经度             |
| 位置名称 | `location_name`        | 地图卡片显示的地点名称 |
| 位置描述 | `location_description` | 地点补充说明           |

### Dock `floating_dock`

| 设置项       | 字段                 | 说明                       |
| ------------ | -------------------- | -------------------------- |
| 定制悬浮栏   | `enable_custom_dock` | 开启后单独配置关于页 Dock  |
| Dock 菜单    | `dock_menu`          | 选择关于页 Dock 使用的菜单 |
| 返回顶部按钮 | `enable_back_to_top` | 是否显示返回顶部入口       |

## 个人信息

| 设置项   | 说明                        |
| -------- | --------------------------- |
| 头像     | 留空时使用站点 Logo         |
| 昵称     | 留空时使用站点名称          |
| 角色     | 用一句话说明身份或定位      |
| 个人简介 | 支持简单 HTML，建议不要过长 |

这些信息也会被首页作者卡片等模块复用，修改前要注意全站显示效果。

## GitHub

| 设置项        | 说明                                 |
| ------------- | ------------------------------------ |
| GitHub 用户名 | 用于生成统计卡片和贡献热力图         |
| 统计卡片      | 显示仓库统计和常用语言               |
| 贡献热力图    | 显示 GitHub Contributions            |
| 服务地址      | 可使用默认服务，也可替换为自部署地址 |
| 语言和主题    | 控制 GitHub 卡片的显示语言和视觉主题 |

如果不想展示 GitHub 内容，清空用户名或关闭对应开关即可。

## 按钮与 CTA

| 设置项   | 说明                                 |
| -------- | ------------------------------------ |
| 主按钮   | 适合跳转作品、项目、文章列表等主入口 |
| 次要按钮 | 适合跳转联系方式或社交链接           |
| CTA 区域 | 页面底部的行动入口，可关闭           |

按钮链接可以写站内锚点、站内路径或完整外链。

## 地图

| 设置项   | 说明                                     |
| -------- | ---------------------------------------- |
| 显示地图 | 控制是否显示位置地图                     |
| 纬度经度 | 使用十进制坐标，例如 `39.9042, 116.4074` |
| 位置名称 | 显示在地图卡片中的地点名称               |
| 位置描述 | 对地点做一句话说明                       |

坐标可以用高德、百度或其他地图拾取工具获取。

## 悬浮控制栏

| 设置项       | 说明                     |
| ------------ | ------------------------ |
| 定制悬浮栏   | 开启后覆盖全局 Dock 配置 |
| Dock 菜单    | 选择当前页面使用的菜单   |
| 返回顶部按钮 | 控制是否显示返回顶部入口 |

## 注意事项

| 场景              | 建议                                            |
| ----------------- | ----------------------------------------------- |
| 页面内容太长      | 保留个人介绍和联系方式，把详细内容放到文章里    |
| GitHub 图片不显示 | 检查 GitHub 用户名和统计服务地址是否可访问      |
| 评论区不显示      | 检查评论插件、页面评论开关和页面 subject        |
| 地图不显示        | 检查经纬度格式，确认浏览器可以加载 Leaflet 资源 |
