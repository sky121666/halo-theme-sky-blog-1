# 朋友圈页面

朋友圈页面用于聚合友站 RSS 动态，适合展示朋友们最近发布的文章。

| 项目     | 说明                                                         |
| -------- | ------------------------------------------------------------ |
| 路由     | `/friends`                                                   |
| 设置位置 | `外观 -> 主题 -> Sky Blog -> 设置 -> 朋友圈`                 |
| 依赖插件 | `plugin-friends`；`PluginLinks` 仅用于首页动态的分组标签增强 |

> `plugin-friends 1.4.6` 上游已归档，但当前主 Halo 与 `PluginLinks 2.0.0`、`link-submit 1.0.7` 组合时三者均为 `STARTED`，`/friends` 已通过深度 smoke。PluginLinks 2.1.0～2.2.1 与后两者组合会触发跨插件 `ObjectMapper` 类加载冲突，因此不能把故障归因于 Friends 单独不兼容 Halo 2.25.4，升级 Links 前必须复验。

## 页面内容

| 区域     | 做什么                       |
| -------- | ---------------------------- |
| 页面头部 | 展示标题和描述               |
| 动态列表 | 展示插件聚合到的友站文章     |
| 列表样式 | 支持单列或双列               |
| 侧边栏   | 可显示作者卡片、统计、标签等 |
| Dock     | 可单独配置悬浮控制栏         |

## 全量配置项

### 基础信息 `basic_info`

| 设置项       | 字段               | 说明                       |
| ------------ | ------------------ | -------------------------- |
| 页面标题     | `page_title`       | 朋友圈页面顶部主标题       |
| 页面描述     | `page_description` | 朋友圈页面顶部说明文字     |
| 列表样式     | `list_style`       | 单列或双列展示             |
| 插件提示文案 | `plugin_tips`      | 插件缺失或数据为空时的提示 |

### 侧边栏 `sidebar_settings`

| 设置项     | 字段                    | 说明                     |
| ---------- | ----------------------- | ------------------------ |
| 显示侧边栏 | `show_sidebar`          | 是否显示朋友圈侧边栏     |
| 定制侧边栏 | `enable_custom_sidebar` | 开启后覆盖全局侧边栏配置 |
| 侧边栏位置 | `sidebar_position`      | 朋友圈侧边栏在左侧或右侧 |
| 小工具列表 | `sidebar_widgets`       | 朋友圈侧边栏小工具列表   |

### Dock `floating_dock`

| 设置项       | 字段                 | 说明                       |
| ------------ | -------------------- | -------------------------- |
| 定制悬浮栏   | `enable_custom_dock` | 开启后单独配置朋友圈 Dock  |
| Dock 菜单    | `dock_menu`          | 选择朋友圈 Dock 使用的菜单 |
| 返回顶部按钮 | `enable_back_to_top` | 是否显示返回顶部入口       |

## 基础设置

| 设置项   | 说明                         |
| -------- | ---------------------------- |
| 页面标题 | 页面顶部主标题               |
| 页面描述 | 页面顶部说明文字             |
| 列表样式 | 单列更稳，双列更适合内容较多 |

每页数量、抓取间隔、RSS 源等数据配置在插件后台完成，不在主题里配置。

## 侧边栏与 Dock

| 设置项       | 说明                     |
| ------------ | ------------------------ |
| 显示侧边栏   | 页面改为左右布局         |
| 定制侧边栏   | 开启后覆盖全局侧边栏     |
| 侧边栏位置   | 左侧或右侧               |
| 小工具列表   | 选择作者卡片、统计等组件 |
| 定制悬浮栏   | 开启后覆盖全局 Dock      |
| 返回顶部按钮 | 控制是否显示返回顶部入口 |

## 插件注意事项

| 场景       | 建议                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------ |
| 页面 404   | 确认 `plugin-friends` 已安装、启用并注册路由                                               |
| 没有动态   | 检查插件后台 RSS 源、抓取任务和友链数据                                                    |
| 页面报错   | 先检查 `plugin-friends` 启动日志；`PluginLinks` 缺失只会关闭分组标签增强，不应中断动态列表 |
| 切页后异常 | 刷新页面复测，确认 PJAX 下插件脚本能重新初始化                                             |

## 灯箱

朋友圈页面主要展示文章链接，不建议单独配置 lightgallery.js 灯箱。
