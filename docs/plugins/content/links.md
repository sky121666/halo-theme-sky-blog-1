# 友情链接页面

友情链接页面用于展示站点分组、友链卡片、本站信息和申请入口。

| 项目     | 说明                                               |
| -------- | -------------------------------------------------- |
| 路由     | `/links`                                           |
| 设置位置 | `外观 -> 主题 -> Sky Blog -> 设置 -> 友链`         |
| 依赖插件 | `PluginLinks`；申请弹窗可选 `link-submit >= 1.0.7` |

## 页面内容

| 区域     | 做什么                                                 |
| -------- | ------------------------------------------------------ |
| 页面头部 | 显示标题和描述                                         |
| 友链列表 | 按插件返回的分组展示站点卡片                           |
| 本站信息 | 弹窗展示本站名称、描述、Logo、RSS 等                   |
| 申请入口 | 插件可用时调用官方申请组件，否则使用主题配置的安全降级 |
| 评论区   | 页面底部评论，可关闭                                   |
| 侧边栏   | 可使用全局侧边栏，也可单独配置                         |

## 全量配置项

### 基础信息 `basic_info`

| 设置项   | 字段               | 说明                       |
| -------- | ------------------ | -------------------------- |
| 页面标题 | `page_title`       | 友链页面顶部主标题         |
| 页面描述 | `page_description` | 友链页面顶部说明文字       |
| 启用评论 | `enable_comment`   | 是否在友链页底部显示评论区 |

### 申请与本站信息 `apply_settings`

| 设置项       | 字段                  | 说明                      |
| ------------ | --------------------- | ------------------------- |
| 启用申请入口 | `enable`              | 是否显示友链申请入口      |
| 申请区标题   | `apply_title`         | 友链申请区域标题          |
| 申请区描述   | `apply_description`   | 说明申请条件或交换规则    |
| 申请地址     | `apply_url`           | 申请按钮跳转地址          |
| 本站 Logo    | `blogger_logo`        | 提供给对方添加友链使用    |
| 本站名称     | `blogger_title`       | 提供给对方添加友链使用    |
| 本站 RSS     | `blogger_rss`         | RSS 地址，常用 `/rss.xml` |
| 联系邮箱     | `blogger_email`       | 友链申请或联系邮箱        |
| 本站描述     | `blogger_description` | 提供给对方添加友链的描述  |

### 侧边栏 `sidebar_settings`

| 设置项     | 字段                    | 说明                     |
| ---------- | ----------------------- | ------------------------ |
| 显示侧边栏 | `show_sidebar`          | 是否显示友链页侧边栏     |
| 定制侧边栏 | `enable_custom_sidebar` | 开启后覆盖全局侧边栏配置 |
| 侧边栏位置 | `sidebar_position`      | 友链页侧边栏在左侧或右侧 |
| 小工具列表 | `sidebar_widgets`       | 友链页侧边栏小工具列表   |

### Dock `floating_dock`

| 设置项       | 字段                 | 说明                       |
| ------------ | -------------------- | -------------------------- |
| 定制悬浮栏   | `enable_custom_dock` | 开启后单独配置友链页 Dock  |
| Dock 菜单    | `dock_menu`          | 选择友链页 Dock 使用的菜单 |
| 返回顶部按钮 | `enable_back_to_top` | 是否显示返回顶部入口       |

| 页面描述   | 页面顶部说明文字       |

## 本站信息

| 设置项   | 说明                    |
| -------- | ----------------------- |
| Logo     | 留空时使用站点默认 Logo |
| 站点名称 | 用于对方添加友链        |
| 站点描述 | 用于对方添加友链        |
| RSS 地址 | 默认可填 `/rss.xml`     |
| 联系邮箱 | 留空时不显示            |

这部分只用于展示和复制，不会自动提交到对方站点。

## 申请入口与降级顺序

主题不实现 `link-submit` 的后端接口，也不自行维护申请表单。插件 `link-submit >= 1.0.7` 可用时，主题按需加载官方 JS/CSS 后调用 `LinkSubmitWidget.open()`；这同时覆盖资源未预注入和 PJAX 重入。插件不可用，或 JS/CSS 加载失败、未完成时，按以下顺序选择入口：

1. 已配置有效 `apply_url`：跳转到该申请地址；空值和占位值 `#`、`/#` 会被忽略。
2. 未配置申请地址但友链评论已开启：跳到本页评论区。
3. 仅配置联系邮箱：打开邮件客户端。
4. 以上均不可用：显示“暂未开放申请”，不向访客展示安装插件提示。

当前主 Halo 使用 `PluginLinks 2.0.0`、`plugin-friends 1.4.6`、`link-submit 1.0.7`，三者均为 `STARTED`。`2.2.34` 真页已验证首次和 PJAX 二次打开官方 Modal，资源与 Modal 不重复，离页自动关闭且控制台无错误。PluginLinks 2.1.0～2.2.1 与后两者组合时会触发跨插件 `ObjectMapper` 类加载冲突，升级前必须重新验证。

## 侧边栏与 Dock

| 设置项       | 说明                     |
| ------------ | ------------------------ |
| 显示侧边栏   | 页面改为左右布局         |
| 定制侧边栏   | 开启后覆盖全局侧边栏     |
| 侧边栏位置   | 左侧或右侧               |
| 小工具列表   | 选择作者卡片、统计等组件 |

| 返回顶部按钮 | 控制是否显示返回顶部入口 |

## 插件注意事项

| 场景               | 建议                                                                                         |
| ------------------ | -------------------------------------------------------------------------------------------- |
| 页面打不开         | 先确认 `PluginLinks` 已安装并启用                                                            |
| 友链为空           | 到插件后台添加友链和分组                                                                     |
| 申请入口不可用     | 检查 `link-submit >= 1.0.7` 状态、官方资源响应，以及申请地址、评论和邮箱配置                 |
| 朋友圈插件同时使用 | 当前固定 PluginLinks 2.0.0；2.1.0～2.2.1 与 Friends/Link Submit 存在已复现的跨插件类加载冲突 |

## 灯箱

友情链接页面不是图片浏览页，通常不需要配置 lightgallery.js 灯箱。
