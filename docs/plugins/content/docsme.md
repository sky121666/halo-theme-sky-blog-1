# 文档页面

> 路径：**外观 → 主题 → Sky Blog → 设置 → 文档**

文档页面依赖 `plugin-docsme`。主题负责页面样式、文档树、正文区域、Dock、分享和评论；文档项目、目录和正文内容由 Docsme 插件提供。

## 页面做什么

| 页面     | 路由                         | 说明                                      |
| -------- | ---------------------------- | ----------------------------------------- |
| 文档首页 | `/docs`                      | 展示所有文档项目                          |
| 文档目录 | `/docs/{project}` 或目录节点 | 展示文档树和当前目录下的文档              |
| 文档正文 | `/docs/**`                   | 展示正文、目录、贡献者、分享、评论和 Dock |

## 版本要求

| 能力                     | 要求                               |
| ------------------------ | ---------------------------------- |
| 文档首页、目录页、正文页 | 跟随 Docsme 官方模板变量和页面协议 |
| 首页“文档中心”模块       | `plugin-docsme >= 1.4.0`           |
| 当前主题适配基线         | `plugin-docsme v1.7.0`             |

## 全量配置项

### 文档内容页 `doc_settings`

| 设置项             | 字段                            | 说明                           |
| ------------------ | ------------------------------- | ------------------------------ |
| 启用分享           | `enable_share`                  | 是否显示文档分享按钮           |
| 启用的分享平台     | `share_settings.share_item_ids` | 选择和排序分享平台             |
| 启用定制 Dock 设置 | `enable_custom_dock`            | 开启后单独配置文档正文页 Dock  |
| Dock 样式          | `dock_style`                    | 底部居中或右侧可折叠           |
| Dock 菜单          | `dock_menu`                     | 选择文档正文页 Dock 菜单       |
| 返回顶部按钮       | `enable_back_to_top`            | 是否显示返回顶部入口           |
| 启用目录抽屉       | `enable_toc_drawer`             | 小屏幕下从 Dock 打开右侧目录   |
| 启用菜单抽屉       | `enable_sidebar_drawer`         | 小屏幕下从 Dock 打开左侧文档树 |

## 文档内容页

内容页对应 `doc.html`，主要用于阅读单篇文档。

| 设置项             | 说明                           | 默认值            |
| ------------------ | ------------------------------ | ----------------- |
| 启用分享           | 是否显示文档分享按钮           | 开启              |
| 启用的分享平台     | 选择分享平台，可拖拽排序       | 微信、微博、X、QQ |
| 启用定制 Dock 设置 | 开启后单独配置文档页 Dock      | 关闭              |
| Dock 样式          | 底部居中或右侧可折叠           | 底部居中          |
| Dock 菜单          | 选择 Dock 使用的菜单           | primary           |
| 返回顶部按钮       | 是否显示返回顶部               | 开启              |
| 启用目录抽屉       | 小屏幕下从 Dock 打开右侧目录   | 开启              |
| 启用菜单抽屉       | 小屏幕下从 Dock 打开左侧文档树 | 开启              |

## 灯箱配置

如果文档正文里有截图、教程图或效果图，建议在 `PluginLightGallery` 后台添加：

| 路由匹配   | 匹配区域           | 说明         |
| ---------- | ------------------ | ------------ |
| `/docs/**` | `#article-content` | 文档正文图片 |

`/docs` 文档首页不需要灯箱，因为首页图片主要是项目图标，不是正文大图。

## 使用建议

| 场景           | 建议                           |
| -------------- | ------------------------------ |
| 纯文字文档     | 可以不配置灯箱，减少资源加载   |
| 教程或配置说明 | 建议配置灯箱，方便放大截图     |
| 文档树很多     | 开启菜单抽屉，移动端更容易导航 |
| 文档正文很长   | 保留目录抽屉和返回顶部按钮     |
