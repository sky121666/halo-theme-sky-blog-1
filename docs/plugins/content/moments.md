# 瞬间页面

瞬间页面用于展示短动态，支持文字、图片、视频、音频、点赞、评论、分享和前端发布。

| 项目     | 说明                                       |
| -------- | ------------------------------------------ |
| 路由     | `/moments`、`/moments/{name}`              |
| 设置位置 | `外观 -> 主题 -> Sky Blog -> 设置 -> 瞬间` |
| 依赖插件 | `plugin-moments`                           |

## 页面内容

| 区域     | 做什么                         |
| -------- | ------------------------------ |
| 瞬间列表 | 展示插件返回的动态列表         |
| 详情页   | 展示单条瞬间、媒体、评论和分享 |
| 标签筛选 | 按插件瞬间标签过滤列表         |
| 媒体展示 | 支持图片、视频和音频           |
| 发布入口 | 登录且具备发布权限后可发布         |
| 侧边栏   | 可使用全局侧边栏，也可单独配置 |

## 全量配置项

### 基础信息 `basic_info`

| 设置项   | 字段             | 说明             |
| -------- | ---------------- | ---------------- |
| 页面标题 | `page_title`     | 瞬间列表页标题   |
| 启用点赞 | `enable_upvote`  | 是否显示点赞按钮 |
| 启用评论 | `enable_comment` | 是否显示评论区域 |

### 侧边栏 `sidebar_settings`

| 设置项     | 字段                    | 说明                     |
| ---------- | ----------------------- | ------------------------ |
| 显示侧边栏 | `show_sidebar`          | 是否显示瞬间页侧边栏     |
| 定制侧边栏 | `enable_custom_sidebar` | 开启后覆盖全局侧边栏配置 |
| 侧边栏位置 | `sidebar_position`      | 瞬间页侧边栏在左侧或右侧 |
| 小工具列表 | `sidebar_widgets`       | 瞬间页侧边栏小工具列表   |

### 前端发布 `publish_settings`

| 设置项       | 字段                  | 说明                         |
| ------------ | --------------------- | ---------------------------- |
| 启用前端发布 | `enable_publish`      | 是否显示有权限用户的前台发布入口 |
| 图片上传     | `enable_image_upload` | 是否允许上传图片             |
| 视频上传     | `enable_video_upload` | 是否允许上传视频             |
| 音频上传     | `enable_audio_upload` | 是否允许上传音频             |

### 分享 `share_settings`

| 设置项         | 字段                            | 说明                         |
| -------------- | ------------------------------- | ---------------------------- |
| 启用分享       | `enable_share`                  | 是否在瞬间详情页显示分享按钮 |
| 启用的分享平台 | `share_settings.share_item_ids` | 选择和排序分享平台           |

### Dock `floating_dock`

| 设置项       | 字段                 | 说明                       |
| ------------ | -------------------- | -------------------------- |
| 定制悬浮栏   | `enable_custom_dock` | 开启后单独配置瞬间页 Dock  |
| Dock 菜单    | `dock_menu`          | 选择瞬间页 Dock 使用的菜单 |
| 返回顶部按钮 | `enable_back_to_top` | 是否显示返回顶部入口       |

## 基础设置

| 设置项   | 说明                     |
| -------- | ------------------------ |
| 页面标题 | 瞬间列表页标题           |
| 启用点赞 | 每条瞬间下方显示点赞按钮 |
| 启用评论 | 每条瞬间下方显示评论区域 |
| 启用分享 | 瞬间详情页显示分享按钮   |

## 前端发布

| 设置项       | 说明                                |
| ------------ | ----------------------------------- |
| 启用前端发布 | 允许有发布权限的登录用户发布          |
| 图片上传     | 允许上传 JPG、PNG、GIF、WebP 等图片 |
| 视频上传     | 允许上传 MP4、WebM 等视频           |
| 音频上传     | 允许上传 MP3、WAV、OGG 等音频       |

发布需要用户已登录，并具备官方 `uc:plugin:moments:publish` 权限；附件上传还需要对应上传权限。主题通过官方 UC 接口提交，由插件确定作者和审核状态。待审核内容会提示已提交，不会直接插入公开列表；拥有免审核权限时，以接口返回的公开状态为准。主题会阻止常见可执行文件类型上传。

前台发布遵循 [PluginMoments 1.19.0 官方编辑器](https://github.com/halo-sigs/plugin-moments/blob/v1.19.0/console/src/uc/MomentEdit.vue)的上限：图片、视频和音频合计最多 9 个附件。一次选择或多次累积超限时，会在上传前提示重新选择，不静默丢弃附件。已有超限内容仍完整展示图片及原图链接。

上传使用 Halo 2.27 的官方 UC 接口，直接读取其返回的 `status.permalink`；缺少地址时提示失败，不再轮询旧附件接口。关闭发布弹窗会取消本次上传等待并恢复按钮，单文件超过 5 分钟未完成会提示重试。客户端取消不会删除服务端可能已经保存的附件。

点赞和评论保留原图标与计数，同时提供读屏名称、点赞状态及评论展开状态。

## 存储建议

| 存储方式 | 图片   | 视频   | 音频   | 建议           |
| -------- | ------ | ------ | ------ | -------------- |
| 本地存储 | 支持   | 支持   | 支持   | 推荐           |
| S3       | 支持   | 支持   | 支持   | 推荐           |
| Lsky     | 支持   | 不支持 | 不支持 | 只适合图片     |
| Alist    | 不建议 | 不建议 | 不建议 | 不作为发布后端 |

瞬间发布链路建议使用本地存储或 S3。Alist 当前不作为主题前端发布的可用后端。

## 分享平台

分享平台可在主题设置中选择和排序。支持微信、X、Telegram、Facebook、QQ、QQ 空间、微博、豆瓣和系统分享。

| 定制侧边栏   | 开启后覆盖全局侧边栏     |

## 灯箱

如果使用 lightgallery.js 插件，推荐在插件后台添加：

| 路径匹配      | 匹配区域        |
| ------------- | --------------- |
| `/moments`    | `.moment-media` |
| `/moments/**` | `.moment-media` |

这样列表页和详情页里的图片都能被插件接管。主题只保留 DOM 结构和 `data-src`，灯箱能力交给插件。

## 常见问题

| 场景       | 建议                                             |
| ---------- | ------------------------------------------------ |
| 发布失败   | 检查登录状态、上传权限、附件存储和插件接口       |
| 媒体不显示 | 检查附件地址是否可访问，视频和音频是否被存储支持 |
| 灯箱不打开 | 检查 lightgallery.js 插件路径和 selector 配置    |
| 页面 404   | 确认 `plugin-moments` 已安装并启用               |
