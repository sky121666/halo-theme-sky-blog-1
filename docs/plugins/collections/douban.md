# 豆瓣页面

豆瓣页面用于展示电影、图书、音乐、游戏和舞台剧收藏记录。

| 项目     | 说明                   |
| -------- | ---------------------- |
| 路由     | `/douban`              |
| 依赖插件 | `plugin-douban`        |
| 适配基线 | `plugin-douban v1.2.5` |

## 页面内容

| 区域     | 做什么                              |
| -------- | ----------------------------------- |
| 页面头部 | 显示标题、说明和总数                |
| 类型筛选 | 按电影、图书、音乐、游戏等类型筛选  |
| 状态筛选 | 展示已看/已读、在看/在读、想看/想读 |
| 题材筛选 | 按插件返回的题材筛选                |
| 海报网格 | 展示封面、标题、评分、年份、备注等  |
| 分页     | 数据较多时分页浏览                  |

## 主题配置边界

当前主题设置中没有独立的 `douban_settings` 分组。主题负责 `/douban` 页面壳、筛选交互、卡片展示和失败占位；账号、同步、图片代理和数据来源都在 `plugin-douban` 后台配置。

## 数据来源

主题页面壳由 `/douban` 路由提供，列表数据通过插件公开 API 获取：

| 接口                                                       | 说明         |
| ---------------------------------------------------------- | ------------ |
| `/apis/api.douban.moony.la/v1alpha1/doubanmovies`          | 获取收藏列表 |
| `/apis/api.douban.moony.la/v1alpha1/doubanmovies/-/types`  | 获取类型     |
| `/apis/api.douban.moony.la/v1alpha1/doubanmovies/-/genres` | 获取题材     |

主题不处理豆瓣同步，数据同步、账号配置和代理配置都在插件后台完成。

## 卡片字段

| 字段     | 说明                     |
| -------- | ------------------------ |
| 标题     | 条目名称                 |
| 封面     | `spec.poster`            |
| 链接     | 豆瓣或插件返回的条目链接 |
| 评分     | 条目评分                 |
| 年份     | 条目年份                 |
| 类型     | 电影、图书、音乐等       |
| 收藏时间 | 用户收藏时间             |
| 备注     | 用户备注，过长会截断     |

## 图片代理

如果插件返回的是豆瓣图片直链，浏览器可能无法直接加载封面。正确做法是在 `plugin-douban` 后台配置图片代理，例如开启 `isProxy` 并设置 `proxyHost`。

主题只做加载失败占位，不在主题里硬编码第三方图片代理。

## 常见问题

| 场景       | 建议                                            |
| ---------- | ----------------------------------------------- |
| 页面 404   | 确认 `plugin-douban` 已安装并启用               |
| 数据为空   | 检查插件是否已经同步豆瓣数据                    |
| 封面不显示 | 检查插件图片代理配置                            |
| 筛选无结果 | 换成“全部”或确认插件返回的数据类型和状态        |
| 接口报错   | 检查插件版本和 `/apis/api.douban.moony.la` 接口 |

## 灯箱

豆瓣页面以海报跳转为主，默认不建议配置 lightgallery.js 灯箱。
