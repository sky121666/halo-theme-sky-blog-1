# 装备页面

装备页面用于展示设备、软件工具、好物清单和分组。

| 项目     | 说明                                       |
| -------- | ------------------------------------------ |
| 路由     | `/equipments`                              |
| 设置位置 | `外观 -> 主题 -> Sky Blog -> 设置 -> 装备` |
| 依赖插件 | `plugin-equipment`                         |

## 页面内容

| 区域     | 做什么                             |
| -------- | ---------------------------------- |
| 页面头部 | 展示标题、描述和页面氛围           |
| 分组切换 | 按插件装备分组切换内容             |
| 装备卡片 | 展示名称、描述、图片、链接、标签等 |
| 展示风格 | 支持 3D 卡片和优雅卡片             |
| 评论区   | 页面底部评论，可关闭               |
| 侧边栏   | 可使用全局侧边栏，也可单独配置     |

## 全量配置项

### 页面提示 `equipment_settings`

| 设置项       | 字段          | 说明                       |
| ------------ | ------------- | -------------------------- |
| 插件提示文案 | `plugin_tips` | 插件缺失或数据为空时的提示 |

### 基础信息 `basic_info`

| 设置项     | 字段               | 说明                       |
| ---------- | ------------------ | -------------------------- |
| 页面标题   | `page_title`       | 装备页面顶部主标题         |
| 页面副标题 | `page_subtitle`    | 装备页面标题旁或标题下补充 |
| 页面描述   | `page_description` | 装备页面顶部说明文字       |

### 样式 `style_settings`

| 设置项    | 字段              | 说明                         |
| --------- | ----------------- | ---------------------------- |
| 显示模式  | `mode`            | 选择 3D 卡片或优雅卡片       |
| Tab 样式  | `tab_style`       | 控制装备分组切换样式         |
| Hero 背景 | `hero_background` | 控制页面头部背景图或背景效果 |

### 功能 `feature_settings`

| 设置项   | 字段             | 说明                       |
| -------- | ---------------- | -------------------------- |
| 启用评论 | `enable_comment` | 是否在装备页底部显示评论区 |

### 侧边栏 `sidebar_settings`

| 设置项     | 字段                    | 说明                     |
| ---------- | ----------------------- | ------------------------ |
| 显示侧边栏 | `show_sidebar`          | 是否显示装备页侧边栏     |
| 定制侧边栏 | `enable_custom_sidebar` | 开启后覆盖全局侧边栏配置 |
| 侧边栏位置 | `sidebar_position`      | 装备页侧边栏在左侧或右侧 |
| 小工具列表 | `sidebar_widgets`       | 装备页侧边栏小工具列表   |

### Dock `floating_dock`

| 设置项       | 字段                 | 说明                       |
| ------------ | -------------------- | -------------------------- |
| 定制悬浮栏   | `enable_custom_dock` | 开启后单独配置装备页 Dock  |
| Dock 菜单    | `dock_menu`          | 选择装备页 Dock 使用的菜单 |
| 返回顶部按钮 | `enable_back_to_top` | 是否显示返回顶部入口       |

## 基础设置

| 设置项   | 说明                       |
| -------- | -------------------------- |
| 页面标题 | 页面顶部主标题             |
| 页面描述 | 页面顶部说明文字           |
| 显示模式 | 选择 3D 卡片或优雅卡片     |
| 启用评论 | 控制页面底部是否显示评论区 |

装备数据来自 `plugin-equipment`，主题只负责页面展示和交互样式。

## 侧边栏与 Dock

| 设置项       | 说明                     |
| ------------ | ------------------------ |
| 显示侧边栏   | 页面改为左右布局         |
| 定制侧边栏   | 开启后覆盖全局侧边栏     |
| 侧边栏位置   | 左侧或右侧               |
| 小工具列表   | 选择作者卡片、统计等组件 |
| 定制悬浮栏   | 开启后覆盖全局 Dock      |
| 返回顶部按钮 | 控制是否显示返回顶部入口 |

## 插件注意事项

| 场景     | 建议                                   |
| -------- | -------------------------------------- |
| 页面 404 | 确认 `plugin-equipment` 已安装并启用   |
| 内容为空 | 到插件后台添加装备分组和装备条目       |
| 图片不显 | 检查装备图片地址和附件访问权限         |
| 样式异常 | 先切换显示模式复测，再检查浏览器控制台 |

## 灯箱

装备页面不是主要图片浏览页，默认不建议配置 lightgallery.js 灯箱。
