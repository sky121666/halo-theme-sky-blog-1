# 追番页面

追番页面用于展示 Bilibili 追番或追剧记录，也可以在侧边栏显示追番卡片。

| 项目     | 说明                                           |
| -------- | ---------------------------------------------- |
| 路由     | `/bangumis`                                    |
| 设置位置 | `外观 -> 主题 -> Sky Blog -> 设置 -> 追番页面` |
| 依赖插件 | `plugin-bilibili-bangumi`                      |

## 页面内容

| 区域       | 做什么                       |
| ---------- | ---------------------------- |
| 页面头部   | 展示标题和描述               |
| 类型切换   | 在追番和追剧之间切换         |
| 状态筛选   | 展示全部、想看、在看、已看完 |
| 番剧列表   | 展示封面、名称、进度和评分   |
| 侧边栏卡片 | 在侧边栏轮播展示指定数量内容 |

## 全量配置项

### 页面设置 `bangumi_settings`

| 设置项       | 字段               | 说明                       |
| ------------ | ------------------ | -------------------------- |
| 插件提示文案 | `plugin_tips`      | 插件缺失或数据为空时的提示 |
| 页面标题     | `page_title`       | 追番页面顶部主标题         |
| 页面描述     | `page_description` | 追番页面顶部说明文字       |

### 侧边栏追番卡片 `card_settings`

| 设置项   | 字段       | 说明                                     |
| -------- | ---------- | ---------------------------------------- |
| 番剧类型 | `type_num` | `1` 为追番，`2` 为追剧                   |
| 番剧状态 | `status`   | `0` 全部，`1` 想看，`2` 在看，`3` 已看完 |
| 展示数量 | `size`     | 控制侧边栏轮播展示多少条                 |

## 基础设置

| 设置项   | 说明             |
| -------- | ---------------- |
| 页面标题 | 页面顶部主标题   |
| 页面描述 | 页面顶部说明文字 |

## 侧边栏追番卡片

| 设置项   | 说明                                     |
| -------- | ---------------------------------------- |
| 番剧类型 | `1` 为追番，`2` 为追剧                   |
| 番剧状态 | `0` 全部，`1` 想看，`2` 在看，`3` 已看完 |
| 展示数量 | 控制侧边栏轮播展示多少条                 |

使用方法：到需要显示的页面侧边栏配置中，添加“追番卡片”小工具。

## 插件配置

| 配置项   | 说明                              |
| -------- | --------------------------------- |
| B 站 UID | Bilibili 个人空间 URL 中的数字 ID |
| 同步设置 | 抓取间隔和同步行为在插件后台配置  |

示例：`https://space.bilibili.com/123456` 中的 `123456` 就是 UID。

## 注意事项

| 场景       | 建议                                  |
| ---------- | ------------------------------------- |
| 页面 404   | 确认追番插件已安装并启用              |
| 数据为空   | 检查 B 站 UID、隐私设置和插件同步任务 |
| 数据不同步 | 先在插件后台手动同步，再刷新前台页面  |
| 卡片不显示 | 确认侧边栏已添加“追番卡片”小工具      |

## 灯箱

追番页面主要展示外部封面和链接，默认不建议配置 lightgallery.js 灯箱。
