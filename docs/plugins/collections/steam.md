# Steam 页面

Steam 页面用于展示 Steam 资料、最近游玩、游戏库、徽章、成就和游玩热力图。

| 项目     | 说明                         |
| -------- | ---------------------------- |
| 路由     | `/steam`                     |
| 主题设置 | 无独立 `steam_settings` 分组 |
| 依赖插件 | `halo-plugin-steam`          |

## 页面内容

| 区域       | 做什么                      |
| ---------- | --------------------------- |
| Steam 资料 | 展示头像、昵称和在线状态    |
| 统计数据   | 展示游戏数、游玩时长等摘要  |
| 最近游玩   | 展示近期游玩的游戏          |
| 游戏库     | 分页展示游戏列表            |
| 成就信息   | 展示成就进度                |
| 热力图     | 展示近期游玩时间分布        |
| 侧边栏卡片 | 在侧边栏展示 Steam 简要信息 |

## 主题配置边界

当前主题设置中没有独立的 `steam_settings` 分组。主题负责 `/steam` 页面壳、异步加载、卡片样式、热力图展示和侧边栏“Steam 卡片”小工具；Steam API Key、SteamID、同步和数据刷新由 `halo-plugin-steam` 后台配置。

Steam 页面模板会消费插件或路由提供的变量，例如 `recentGamesLimit`、`gamesPageSize`、`showHeatmap`、`heatmapDays` 和 `enableGameLink`。这些不是当前主题设置面板里的字段，文档里不要当成主题配置项维护。

## 插件配置

| 配置项        | 说明                       |
| ------------- | -------------------------- |
| Steam API Key | 在 Steam 开发者页面获取    |
| Steam ID      | 使用 64 位 SteamID         |
| 同步设置      | 数据刷新间隔由插件后台控制 |

Steam 资料需要设置为公开，否则插件可能拿不到完整游戏库和最近游玩数据。

## 侧边栏卡片

使用方法：到需要显示的页面侧边栏配置中，添加“Steam 卡片”小工具。

卡片会展示头像、昵称、在线状态、统计信息和最近游玩摘要。

## 注意事项

| 场景       | 建议                                   |
| ---------- | -------------------------------------- |
| 页面 404   | 确认 Steam 插件已安装并启用            |
| 数据为空   | 检查 Steam API Key、SteamID 和隐私设置 |
| 接口失败   | 检查服务器是否能访问 Steam API         |
| 卡片不显示 | 确认侧边栏已添加“Steam 卡片”小工具     |

## 灯箱

Steam 页面不是图片浏览页，默认不建议配置 lightgallery.js 灯箱。
