# v2.2.41：Halo 2.27 适配与页面稳定性修复

本版最低要求为 **Halo 2.27.0**，本地最终验证环境为 **Halo 2.27.2**；不再声明支持 Halo 2.26。各可选插件仍须满足其自身的版本要求。

## 主要变化

- **页面切换与代码高亮**：修复慢资源加载、快速切页和迟到回调引起的错误刷新、遗漏初始化及错页更新。Shiki 延迟启动完成后能恢复当前正文高亮；配置改变、离开适用范围或执行结果尚不确定时，保留整页导航恢复。
- **图库**：修复分页追加和灯箱关闭后的滚动跳动，按已知图片尺寸预留空间；补齐小分页继续加载、重复分页保护、坏图重试、键盘入口和离页清理，保留原有瀑布流与图片比例。
- **分类与标签**：完善分类层级、当前项折叠及空列表呈现；修复长标题、摘要和标签撑宽手机页面的问题。极简列表的长标签可自然换行，阅读数和“阅读更多”保持正常横排；无标签时保留原有对齐。
- **Docsme**：对齐官方文档字段、正文和评论主体，统一版本/语言选择入口；切换时保留当前正文路径，修复抽屉断点、空目录锁滚动、目录定位及公式在 PJAX 返回后的重复处理。
- **导航与认证**：完善手机菜单的焦点、Tab 约束、Escape/遮罩关闭和跨断点清理，保留站内链接的主题预览身份。适配 Halo 2.27 验证码与核心认证脚本，修复密码显隐、保持登录状态、失败反馈及短屏布局。
- **友链与瞬间**：完善友链识别、详情、分页历史、权限降级和失败重试，避免旧请求覆盖新输入。瞬间发布遵循官方 UC 权限、审核状态、上传响应和附件数量限制，补齐取消、超时与草稿保护；历史多媒体内容保留完整入口。
- **组件与其他页面**：按插件已有能力处理联系表单、AI 摘要、受限阅读等宿主的按需加载、明暗状态和离页清理。修复 Steam/豆瓣分页与异步状态、装备长规格和窄屏布局、独立页面封面、关于页地图降级，以及复制/分享失败反馈。

本版保持原有字体、配色、图标和各页主要布局；减少重复说明，补充必要的状态反馈与可访问性。插件没有提供的主题接口不补造功能。

## 构建依赖与安全

- Vite 更新至 `8.3.6`，source-map-js 更新至 `1.2.2`；glob/minimatch 采用已修复并通过 pnpm 发布冷却期的 `14.0.3` / `11.0.4`。
- 2026-11-06 查询到的 glob `14.0.4`、minimatch `11.0.5` 及其依赖组合会触发冷却期豁免，本版未降低供应链策略。此处不表示所有依赖均为当日最新版本。
- 本地全量依赖审计由 **9 条开发依赖告警降至 0**，生产依赖审计也为 0。保留冻结安装、完整 audit 和质量门禁；限定消费者版本的 override 已做实际匹配及打包行为对比，不作为任意旧 API 的兼容承诺。

- 冻结安装、完整构建、lint、格式及差异检查通过；构建回归 **577/577，0 跳过**。
- 44 个路由/视图在桌面与手机完成 **88 组**巡检；最后调整无标签阅读区对齐后，在最终代码上追加 **18 组**相关路由复验。两批代码身份分别记录，不将此前 88 组改写为最终版本的全量重跑。
- 四种实际 Thymeleaf 列表，覆盖正常内容、长标题、长摘要、长标签及空标签，结合两种视口与侧栏开关，完成 **80 组隔离布局验证**。手机标签页由 501px 溢出恢复到 390px；长标签阅读入口保持单行。

## 适配与验证边界

本版按插件官方已有能力适配，不宣称所有插件、配置和业务均已通过。Contact Form、AI Summary、Restricted Reading 仍缺少部分真实正文宿主样本；官方组件的隔离验证不能替代实际正文注入、模型生成、提交与持久化回读、支付解锁、外部 SSO 或完整 WebAuthn 验证。用户此前手测 AI/Passkey 的结果保留其来源，不改写为本次自动化测试结果。

AList 不在本次修复与验收范围；无主题接入点的后台、编辑器和调度能力不列为主题缺陷。逐插件范围与历史证据见[当前适配结果](../system/adaptation/current-plugin-results.md)。
