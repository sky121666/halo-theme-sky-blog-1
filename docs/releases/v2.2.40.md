# v2.2.40：Halo 2.26 与前端依赖适配

## 变化

- 主题最低 Halo 版本提高到 `2.26.0`，沿用官方 `layout.html` 布局契约；Halo 2.25 及更早版本不能安装本版。
- 升级 Alpine.js、Swup、daisyUI、Vite、TypeScript 等前端与构建依赖，生成 `2.2.40` 版本化资源，避免页面缓存继续引用旧版脚本和样式。Node 版本文件和 CI 固定为 `24.21.0`，包管理器为 pnpm `12.6.0`。
- CD 打包任务补齐 lint 和格式检查，与标签 Quality Gate 的主要质量门禁保持一致。

## 发布前验证

- Node `24.21.0` / pnpm `12.6.0`：无例外冻结安装、lint、格式、依赖审计及完整构建通过；27 项静态插件契约和 33 项插件读取检查通过，审计报告 0 个已知漏洞。
- 本地 Halo Pro `2.26.1` 临时激活本主题并刷新页面缓存：114 个 URL 为 113 个 200、已移除入口的 `/terms` 为预期 404。真实浏览器验证首页→文章 PJAX、404 回退后返回文章、独立日历整页导航，以及 390px 友链页；测试后恢复原激活主题。
- AI Assistant `3.1.0`、Restricted Reading `1.9.1`、Schedule Calendar `3.5.0` 的主题相关读取和展示表面已定向复测；自动摘要注入、匿名受限组件完整交互及插件后台业务不在通过范围。环境、源码指纹及测试边界见[依赖适配记录](../system/development/dependency-upgrade-2026-09-24.md#2026-09-25-发布前复核)。
