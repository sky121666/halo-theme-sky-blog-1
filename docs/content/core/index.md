# 首页设置

首页用于承接站点首屏、文章列表、插件内容聚合和常用入口，是主题最主要的展示页面。

| 项目     | 说明                                       |
| -------- | ------------------------------------------ |
| 路由     | `/`                                        |
| 设置位置 | `外观 -> 主题 -> Sky Blog -> 设置 -> 首页` |

## 首页结构

| 区域       | 做什么                                         |
| ---------- | ---------------------------------------------- |
| 头部区域   | 展示背景、标题、副标题、波浪过渡和瞬间说说     |
| 侧边栏     | 展示作者卡片、统计、分类、标签、插件卡片等     |
| 模块流     | 控制热力图、文档中心、内容聚合、图库、友链顺序 |
| 内容聚合区 | 用 Tab 展示文章、朋友动态和瞬间说说            |
| 悬浮 Dock  | 首页可单独配置悬浮控制栏                       |

## 全量配置项

### 模块排序 `index_layout`

| 设置项       | 字段      | 说明                         |
| ------------ | --------- | ---------------------------- |
| 模块自由排序 | `enabled` | 开启后可拖拽控制首页模块顺序 |
| 模块列表     | `modules` | 选择首页模块，并控制显示顺序 |

### 头部背景 `background_settings`

| 设置项       | 字段                 | 说明                           |
| ------------ | -------------------- | ------------------------------ |
| 启用首页头部 | `enable_header`      | 总开关，关闭后隐藏首页首屏头部 |
| 背景类型     | `background_type`    | 无、图片、特效或天气联动背景   |
| 背景图片     | `background_image`   | 图片或视频地址                 |
| 特效样式     | `effect_style`       | 流体渐变、霓虹线条、深邃星空等 |
| 浅色蒙版方案 | `light_scheme`       | 浅色主题下的背景蒙版方案       |
| 浅色自定义色 | `light_custom_color` | 浅色主题下的自定义蒙版颜色     |
| 深色蒙版方案 | `dark_scheme`        | 深色主题下的背景蒙版方案       |
| 深色自定义色 | `dark_custom_color`  | 深色主题下的自定义蒙版颜色     |

### 标题 `title_settings`

| 设置项       | 字段                | 说明                         |
| ------------ | ------------------- | ---------------------------- |
| 显示主标题   | `show_title`        | 是否显示首页主标题           |
| 自定义主标题 | `custom_title`      | 留空时使用 Halo 系统站点标题 |
| 标题字体     | `title_font`        | 控制主标题字体               |
| 标题样式     | `style_effect`      | 控制主标题视觉效果           |
| 效果颜色     | `effect_color`      | 控制标题效果主色             |
| 装饰效果     | `decoration_effect` | 控制标题旁或标题后的装饰     |

### 副标题 `subtitle_settings`

| 设置项     | 字段              | 说明                       |
| ---------- | ----------------- | -------------------------- |
| 显示副标题 | `show_subtitle`   | 是否显示首页副标题         |
| 副标题文案 | `subtitle_text`   | 一句话说明站点内容         |
| 副标题字体 | `subtitle_font`   | 控制副标题字体             |
| 副标题效果 | `subtitle_effect` | 打字机、渐变流动、微发光等 |
| 副标题颜色 | `subtitle_color`  | 控制副标题文字颜色         |

### 波浪过渡 `wave_transition_settings`

| 设置项       | 字段                   | 说明                       |
| ------------ | ---------------------- | -------------------------- |
| 显示波浪过渡 | `show_wave_transition` | 是否在头部底部显示波浪过渡 |
| 波浪颜色     | `wave_color`           | 控制波浪颜色               |

### 首屏瞬间 `moment_settings`

| 设置项   | 字段           | 说明                       |
| -------- | -------------- | -------------------------- |
| 显示瞬间 | `show_moment`  | 是否在首页头部展示瞬间入口 |
| 瞬间标题 | `moment_title` | 首屏瞬间模块标题           |

### 侧边栏 `sidebar_settings`

| 设置项     | 字段                    | 说明                       |
| ---------- | ----------------------- | -------------------------- |
| 显示侧边栏 | `show_sidebar`          | 控制首页是否显示侧边栏     |
| 定制侧边栏 | `enable_custom_sidebar` | 开启后覆盖全局侧边栏配置   |
| 侧边栏位置 | `sidebar_position`      | 首页侧边栏在左侧或右侧     |
| 小工具列表 | `sidebar_widgets`       | 首页侧边栏小工具列表和顺序 |

### 内容区 `content_settings`

| 设置项     | 字段           | 说明                              |
| ---------- | -------------- | --------------------------------- |

## 模块自由排序

开启“模块自由排序”后，可以拖拽控制首页模块顺序。

| 模块       | 依赖                         |
| ---------- | ---------------------------- |
| 热力图     | GitHub 用户名或文章数据      |
| 文档中心   | `plugin-docsme`              |
| 内容聚合区 | 文章数据，可选朋友动态和瞬间 |
| 图库区     | `plugin-photos`              |
| 友情链接区 | `PluginLinks`                |

如果关闭自由排序，首页会使用主题默认顺序。

## 头部区域

| 设置项       | 说明                               |
| ------------ | ---------------------------------- |
| 启用首页头部 | 总开关，关闭后隐藏头部相关内容     |
| 背景类型     | 无、背景图片、CSS 特效、天气联动   |
| 背景媒体     | 背景图片或视频地址                 |
| 特效样式     | 流体渐变、霓虹线条、深邃星空       |
| 蒙版颜色     | 分别控制浅色和深色主题下的背景遮罩 |
| 波浪过渡     | 控制头部底部的过渡效果             |

天气联动依赖天气小工具的数据能力，如果天气接口不可用，会回退到普通显示。

## 标题与副标题

| 设置项     | 说明                                             |
| ---------- | ------------------------------------------------ |
| 主标题     | 留空时使用站点标题                               |
| 标题字体   | 系统默认、Monoton、Titan One、霞鹜文楷亮、思源宋 |
| 标题效果   | 麦克笔感、斜切双色、流光、发光、阴影等           |
| 副标题     | 一句话说明站点内容                               |
| 副标题效果 | 打字机、渐变流动、微发光、呼吸等                 |

首页标题不要写太长，否则移动端容易拥挤。

## 内容聚合区

| Tab      | 说明              | 依赖             |
| -------- | ----------------- | ---------------- |
| 全部文章 | 展示最新文章列表  | Halo 文章数据    |
| 朋友动态 | 展示朋友 RSS 动态 | `plugin-friends` |
| 瞬间说说 | 展示最新瞬间      | `plugin-moments` |

可配置 Tab 样式和显示顺序。文章列表支持卡片、列表、杂志和极简四种样式。

## 插件模块

| 模块     | 设置项                       | 依赖插件        |
| -------- | ---------------------------- | --------------- |
| 图库     | 标题、副标题、是否启用       | `plugin-photos` |
| 友情链接 | 标题、副标题、分组、数量     | `PluginLinks`   |
| 文档中心 | 标题、副标题、数量、默认图标 | `plugin-docsme` |

这些模块只负责首页展示。完整列表页仍然在各插件自己的路由中。

## 常见问题

| 场景           | 建议                                       |
| -------------- | ------------------------------------------ |
| 首页模块不显示 | 确认模块开关已打开，依赖插件已安装并启用   |
| 朋友动态为空   | 检查 `plugin-friends` 抓取和 RSS 配置      |
| 瞬间说说为空   | 检查 `plugin-moments` 是否已有公开内容     |
| 文档中心为空   | 检查 Docsme 项目是否有文档，并且插件已启用 |
| 移动端拥挤     | 减少首屏标题长度，关闭不必要的头部特效     |
