# 文章页设置

> 路径：**外观 -> 主题 -> Sky Blog -> 设置 -> 文章**

文章页设置控制单篇文章的头图、摘要、侧边栏、互动按钮、评论和 Dock。

## 页面结构

| 区域     | 作用                                     |
| -------- | ---------------------------------------- |
| 文章头部 | 显示标题、元信息和背景图                 |
| 正文区域 | 显示文章内容、代码块、图片和扩展插件内容 |
| 侧边栏   | 显示目录、作者、分类、标签等小工具       |
| 底部互动 | 点赞、分享、评论                         |
| Dock     | 返回顶部、目录抽屉、快捷菜单             |

## 全量配置项

### 头部背景 `header_background`

| 设置项         | 字段              | 说明                             |
| -------------- | ----------------- | -------------------------------- |
| 背景图片来源   | `background_type` | 使用文章封面、自定义图片或无背景 |
| 自定义背景图片 | `custom_image`    | 上传或填写文章页统一背景图       |
| 启用回退图片   | `enable_fallback` | 没有背景图时是否使用默认图       |
| 回退图片       | `fallback_image`  | 默认背景图地址                   |

### 内容显示 `content_settings`

| 设置项       | 字段           | 说明                     |
| ------------ | -------------- | ------------------------ |
| 显示文章摘要 | `show_excerpt` | 是否在正文前展示文章摘要 |

### 版权说明 `copyright_notice`

| 设置项       | 字段            | 说明                                |
| ------------ | --------------- | ----------------------------------- |
| 启用版权说明 | `enable`        | 是否在文章底部显示版权说明          |
| 类型         | `type`          | 原创、转载、翻译、AI 辅助等版权类型 |
| 原文标题     | `source_title`  | 转载或引用来源标题                  |
| 原文链接     | `source_url`    | 转载或引用来源地址                  |
| 原作者       | `source_author` | 转载或引用来源作者                  |
| AI 工具      | `ai_tool`       | 使用的 AI 工具名称                  |
| AI 用途      | `ai_usage`      | AI 参与内容生成、润色或摘要的范围   |
| 许可名称     | `license_name`  | 版权许可名称                        |
| 许可链接     | `license_url`   | 版权许可说明链接                    |
| 备注         | `note`          | 额外版权说明                        |

### 侧边栏 `sidebar_settings`

| 设置项     | 字段                    | 说明                     |
| ---------- | ----------------------- | ------------------------ |
| 显示侧边栏 | `show_sidebar`          | 是否显示文章侧边栏       |
| 定制侧边栏 | `enable_custom_sidebar` | 开启后覆盖全局侧边栏配置 |
| 侧边栏位置 | `sidebar_position`      | 文章侧边栏在左侧或右侧   |
| 小工具列表 | `sidebar_widgets`       | 文章页侧边栏小工具列表   |

### 互动功能 `post_interaction`

| 设置项         | 字段                            | 说明               |
| -------------- | ------------------------------- | ------------------ |
| 启用点赞       | `enable_like`                   | 是否显示点赞按钮   |
| 启用分享       | `enable_share`                  | 是否显示分享按钮   |
| 启用评论       | `enable_comment`                | 是否显示评论区     |
| 启用的分享平台 | `share_settings.share_item_ids` | 选择和排序分享平台 |

### Dock `dock_settings`

| 设置项        | 字段                 | 说明                           |
| ------------- | -------------------- | ------------------------------ |
| 启用定制 Dock | `enable_custom_dock` | 开启后单独配置文章页 Dock      |
| Dock 样式     | `dock_style`         | 跟随全局、底部居中或右侧可折叠 |
| Dock 菜单     | `post_dock_menu`     | 选择文章页 Dock 使用的菜单     |
| 目录抽屉      | `enable_toc_drawer`  | 小屏幕下从 Dock 打开文章目录   |
| 返回顶部按钮  | `enable_back_to_top` | 是否显示返回顶部入口           |

## 头部背景

| 设置项         | 作用                         |
| -------------- | ---------------------------- |
| 背景图片来源   | 使用文章封面或自定义图片     |
| 自定义背景图片 | 上传图片或填写 URL           |
| 启用回退图片   | 没有背景图时使用默认图       |
| 回退图片       | 默认背景图，可使用随机图 API |

## 内容显示

| 设置项       | 作用                           | 建议                       |
| ------------ | ------------------------------ | -------------------------- |
| 显示文章摘要 | 在正文前展示摘要，并带打字效果 | 安装 AI 摘要插件时建议关闭 |

如果同时显示主题摘要和 AI 摘要，页面会显得重复。

## 侧边栏

| 设置项     | 作用                     |
| ---------- | ------------------------ |
| 显示侧边栏 | 是否显示文章侧边栏       |
| 定制侧边栏 | 开启后覆盖全局侧边栏配置 |
| 侧边栏位置 | 左侧或右侧               |
| 小工具列表 | 拖拽排序小工具           |

文章页推荐保留“文章目录”。长文阅读时，目录比其它小工具更重要。

## 互动功能

| 设置项         | 作用                         |
| -------------- | ---------------------------- |
| 启用点赞       | 显示点赞按钮                 |
| 启用分享       | 显示分享按钮                 |
| 启用的分享平台 | 选择微信、微博、X、QQ 等平台 |
| 启用评论       | 显示评论区                   |

评论依赖评论插件。分享二维码和弹窗由主题渲染。

## Dock

| 设置项           | 作用                           |
| ---------------- | ------------------------------ |
| 启用定制 Dock    | 单独配置文章页 Dock            |
| Dock 样式        | 跟随全局、底部居中、右侧可折叠 |
| 文章页 Dock 菜单 | 选择文章页 Dock 菜单           |
| 启用目录抽屉     | 移动端从 Dock 打开目录         |
| 返回顶部按钮     | 是否显示返回顶部               |

移动端建议开启目录抽屉，避免侧边栏隐藏后文章目录不可用。
