# 内容页面

内容页面按“核心页面”和“内容列表”拆分。

| 二级目录   | 内容                           | 入口                             |
| ---------- | ------------------------------ | -------------------------------- |
| `core`     | 首页、文章页                   | [核心页面](./core/README.md)     |
| `taxonomy` | 分类页、标签页、归档页、作者页 | [内容列表](./taxonomy/README.md) |

## 使用顺序

| 顺序 | 操作                                               |
| ---- | -------------------------------------------------- |
| 1    | 先配置首页和文章页，保证主访问链路完整             |
| 2    | 再配置分类、标签、归档，保证内容列表体验一致       |
| 3    | 最后配置作者页，确认文章和瞬间展示符合站点内容结构 |
