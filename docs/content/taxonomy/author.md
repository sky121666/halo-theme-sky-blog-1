# 作者页设置

> 路径：**外观 -> 主题 -> Sky Blog -> 设置 -> 作者**

作者页展示某个作者的资料、文章和瞬间。

## 页面内容

| 区域     | 说明                                     |
| -------- | ---------------------------------------- |
| 作者资料 | 头像、昵称、简介等信息                   |
| 文章列表 | 展示该作者发布的文章                     |
| 瞬间列表 | 展示该作者发布的瞬间，需要 PluginMoments |
| 侧边栏   | 展示小工具                               |

## 全量配置项

### 侧边栏 `sidebar_settings`

| 设置项     | 字段                    | 说明                     |
| ---------- | ----------------------- | ------------------------ |
| 显示侧边栏 | `show_sidebar`          | 是否显示作者页侧边栏     |
| 定制侧边栏 | `enable_custom_sidebar` | 开启后覆盖全局侧边栏配置 |
| 侧边栏位置 | `sidebar_position`      | 作者页侧边栏在左侧或右侧 |
| 小工具列表 | `sidebar_widgets`       | 作者页侧边栏小工具列表   |

### 内容显示 `content_settings`

| 设置项       | 字段        | 说明                   |
| ------------ | ----------- | ---------------------- |
| 文章每页数量 | `page_size` | 作者页文章列表每页数量 |

作者页的“瞬间”Tab 由模板自动判断：安装并启用 `plugin-moments`，且该作者有公开瞬间时才显示。当前主题后台没有单独的作者页瞬间开关。

### Dock `floating_dock`

| 设置项         | 字段                 | 说明                       |
| -------------- | -------------------- | -------------------------- |
| 定制悬浮控制栏 | `enable_custom_dock` | 开启后单独配置作者页 Dock  |
| Dock 样式      | `dock_style`         | 底部居中或右侧可折叠       |
| Dock 菜单      | `dock_menu`          | 选择作者页 Dock 使用的菜单 |
| 返回顶部按钮   | `enable_back_to_top` | 是否显示返回顶部入口       |

## 内容设置

| 设置项       | 作用                   | 默认值 |
| ------------ | ---------------------- | ------ |
| 文章每页数量 | 作者页文章列表每页数量 | 10     |

作者页会自动展示文章列表。瞬间内容不是后台字段，见上方说明。

## 侧边栏

| 设置项     | 作用                 | 默认值 |
| ---------- | -------------------- | ------ |
| 显示侧边栏 | 是否显示侧边栏       | 开启   |
| 定制侧边栏 | 单独配置作者页侧边栏 | 关闭   |
| 侧边栏位置 | 左侧或右侧           | 右侧   |
| 小工具列表 | 拖拽排序小工具       | -      |

作者页常用小工具：博客统计、文章分类、标签云、热门文章、最新文章。

## Dock

| 设置项         | 作用                 | 默认值     |
| -------------- | -------------------- | ---------- |
| 定制悬浮控制栏 | 单独配置作者页 Dock  | 关闭       |
| Dock 样式      | 底部居中或右侧可折叠 | 右侧可折叠 |
| Dock 菜单      | 选择菜单             | primary    |
| 返回顶部按钮   | 是否显示             | 开启       |
