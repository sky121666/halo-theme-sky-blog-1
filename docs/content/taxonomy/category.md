# 分类页设置

> 路径：**外观 -> 主题 -> Sky Blog -> 设置 -> 分类**

分类页展示某个分类下的文章，并提供分类切换、文章列表、侧边栏和 Dock。

## 页面内容

| 区域     | 说明                   |
| -------- | ---------------------- |
| 分类标题 | 显示当前分类名称和描述 |
| 分类切换 | 在不同分类之间切换     |
| 文章列表 | 展示当前分类下的文章   |
| 侧边栏   | 展示小工具             |

## 全量配置项

### 基础信息 `basic_info`

| 设置项         | 字段                     | 说明                     |
| -------------- | ------------------------ | ------------------------ |
| 文章列表风格   | `list_style`             | 控制分类文章列表展示样式 |
| 分类切换块风格 | `category_display_style` | 控制分类切换区域样式     |

### 侧边栏 `sidebar_settings`

| 设置项     | 字段                    | 说明                     |
| ---------- | ----------------------- | ------------------------ |
| 显示侧边栏 | `show_sidebar`          | 是否显示分类页侧边栏     |
| 定制侧边栏 | `enable_custom_sidebar` | 开启后覆盖全局侧边栏配置 |
| 侧边栏位置 | `sidebar_position`      | 分类页侧边栏在左侧或右侧 |
| 小工具列表 | `sidebar_widgets`       | 分类页侧边栏小工具列表   |

### 封面回退 `cover_fallback`

| 设置项       | 字段            | 说明                       |
| ------------ | --------------- | -------------------------- |
| 启用封面替代 | `enable`        | 文章无封面时是否使用默认图 |
| 替代模式     | `mode`          | 仅无封面替代或始终替代     |
| 默认封面图片 | `default_image` | 分类页文章列表默认封面     |

### Dock `floating_dock`

| 设置项         | 字段                 | 说明                       |
| -------------- | -------------------- | -------------------------- |
| 定制悬浮控制栏 | `enable_custom_dock` | 开启后单独配置分类页 Dock  |
| Dock 菜单      | `dock_menu`          | 选择分类页 Dock 使用的菜单 |
| 返回顶部按钮   | `enable_back_to_top` | 是否显示返回顶部入口       |

## 侧边栏

| 设置项     | 作用                 | 默认值 |
| ---------- | -------------------- | ------ |
| 显示侧边栏 | 是否显示侧边栏       | 开启   |
| 定制侧边栏 | 单独配置分类页侧边栏 | 关闭   |
| 侧边栏位置 | 左侧或右侧           | 右侧   |
| 小工具列表 | 拖拽排序小工具       | -      |

可用小工具：欢迎卡片、作者卡片、博客统计、文章分类、标签云、热门文章、最新文章。

## 列表样式

| 设置项         | 作用                         | 默认值 |
| -------------- | ---------------------------- | ------ |
| 文章列表风格   | 卡片、列表、杂志、极简       | 卡片   |
| 分类切换块风格 | 药丸、芯片、下划线、玻璃拟态 | 芯片   |

## 分类图标

分类图标不在主题设置里配置，而是在 Halo 分类元数据里配置：

1. 进入 `文章 -> 分类`。
2. 编辑分类。
3. 打开元数据或附加设定。
4. 添加字段 `icon`。
5. 填入 Iconify 图标名或图标值。

## 封面回退

| 设置项       | 作用                   | 默认值       |
| ------------ | ---------------------- | ------------ |
| 启用封面替代 | 无封面时使用默认图     | 关闭         |
| 替代模式     | 无封面时替代或始终替代 | 无封面时替代 |
| 默认封面图片 | 上传默认封面           | -            |

## Dock

| 设置项         | 作用                | 默认值  |
| -------------- | ------------------- | ------- |
| 定制悬浮控制栏 | 单独配置分类页 Dock | 关闭    |
| Dock 菜单      | 选择菜单            | primary |
| 返回顶部按钮   | 是否显示            | 开启    |
