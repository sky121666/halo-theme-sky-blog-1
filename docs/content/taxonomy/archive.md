# 归档页设置

> 路径：**外观 -> 主题 -> Sky Blog -> 设置 -> 归档**

归档页按时间展示文章，适合让访客按年份和月份浏览历史内容。

## 页面内容

| 区域     | 说明                         |
| -------- | ---------------------------- |
| 归档标题 | 显示归档页标题和统计         |
| 时间列表 | 按年份、月份展示文章         |
| 归档探索 | 侧边栏里按年份和月份快速跳转 |
| 评论区   | 可选，用于归档页留言         |

## 全量配置项

### 基础信息 `basic_info`

| 设置项   | 字段             | 说明                       |
| -------- | ---------------- | -------------------------- |
| 启用评论 | `enable_comment` | 是否在归档页底部显示评论区 |

### 侧边栏 `sidebar_settings`

| 设置项       | 字段                           | 说明                       |
| ------------ | ------------------------------ | -------------------------- |
| 显示侧边栏   | `show_sidebar`                 | 是否显示归档页侧边栏       |
| 定制侧边栏   | `enable_custom_sidebar`        | 开启后覆盖全局侧边栏配置   |
| 侧边栏位置   | `sidebar_position`             | 归档页侧边栏在左侧或右侧   |
| 小工具列表   | `sidebar_widgets`              | 归档页侧边栏小工具列表     |
| 归档探索标题 | `archive_sidebar_config.title` | 控制归档探索小工具标题     |
| 归档探索图标 | `archive_sidebar_config.icon`  | 控制归档探索小工具标题图标 |

### Dock `floating_dock`

| 设置项         | 字段                 | 说明                       |
| -------------- | -------------------- | -------------------------- |
| 定制悬浮控制栏 | `enable_custom_dock` | 开启后单独配置归档页 Dock  |
| Dock 菜单      | `dock_menu`          | 选择归档页 Dock 使用的菜单 |
| 返回顶部按钮   | `enable_back_to_top` | 是否显示返回顶部入口       |

## 侧边栏

| 设置项     | 作用                 | 默认值 |
| ---------- | -------------------- | ------ |
| 显示侧边栏 | 是否显示侧边栏       | 关闭   |
| 定制侧边栏 | 单独配置归档页侧边栏 | 关闭   |
| 侧边栏位置 | 左侧或右侧           | 右侧   |
| 小工具列表 | 拖拽排序小工具       | -      |

归档页推荐使用“归档探索”小工具，方便按年月跳转。

## 评论

| 设置项   | 作用                   | 默认值 |
| -------- | ---------------------- | ------ |
| 启用评论 | 在归档页底部显示评论区 | 关闭   |

如果开启评论，建议在 Halo 后台创建 slug 为 `archives` 的自定义页面，避免评论主体名称显示异常。

## Dock

| 设置项         | 作用                | 默认值  |
| -------------- | ------------------- | ------- |
| 定制悬浮控制栏 | 单独配置归档页 Dock | 关闭    |
| Dock 菜单      | 选择菜单            | primary |
| 返回顶部按钮   | 是否显示            | 开启    |
